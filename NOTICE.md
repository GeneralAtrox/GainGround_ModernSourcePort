# Source provenance and third-party notices

Gain Ground is a Sega game. Its name identifies the supported original product;
this project is not an official Sega release or an assertion of endorsement.

This port was developed through reverse engineering, including mechanical
translation of original instruction behavior. It is not a clean-room rewrite.
Removing ROMs, extracted assets and copied data tables does not determine whether
the remaining translated code may be redistributed in every jurisdiction.
No blanket license over the original game or its translated expression is
granted here. Public-release clearance remains a separate decision.

ROMs, disk images, keys, graphics, audio, icons and memory captures are not
included in the source package. Users supply compatible game data for local
extraction. The importer does not fetch or distribute it.

The System 24 adaptations retain their BSD-3-Clause attribution in
[native/third_party/SYSTEM24-NOTICE.txt](native/third_party/SYSTEM24-NOTICE.txt).
The vendored ymfm files retain Aaron Giles' BSD-3-Clause copyright and license
text in each file. These notices must remain with redistributions.
